# AWS 3-Tier Web Architecture

## Overview

This project demonstrates a scalable and highly available 3-tier architecture deployed on AWS following AWS Well-Architected Framework best practices.

## Architecture

- Amazon VPC
- Public and Private Subnets
- Internet Gateway
- NAT Gateway
- Application Load Balancer
- EC2 Auto Scaling Group
- Amazon RDS (MySQL)
- Security Groups
- CloudWatch Monitoring
